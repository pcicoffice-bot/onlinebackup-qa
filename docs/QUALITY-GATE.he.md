## איפה רואים
GitHub ← Actions ← הריצה האחרונה. ירוק = עבר. אדום = נכשל, ובתוך הריצה יש דוח עם צילומי מסך של כל בעיה (`screen-check-report`, `website-check-report`).
GitHub שולח מייל אוטומטי כשריצה נכשלת.

## לפני שליחה — אותה בדיקה במחשב המפתח
```
OB_RESTIC=/path/restic tools/check-all.sh
```
מסתיים ב-`QUALITY GATE OK` או נעצר בבעיה הראשונה.

## צעד אחד שרק בעל המאגר יכול לעשות: נעילת הענף
כדי שגם אדם לא יוכל לעקוף את השער:
GitHub ← Settings ← Branches ← Add branch ruleset ← ענף `online-backup`:
- ✅ Require a pull request before merging
- ✅ Require status checks to pass: `tests`, `screens`, `website`
- ✅ Block force pushes

מאותו רגע כל פיתוח נכנס רק דרך Pull Request, ורק אחרי שכל הבדיקות ירוקות.
