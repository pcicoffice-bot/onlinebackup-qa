# אפיון — עיצוב, צבעים ושפה

## DESIGN-010 — שני צבעים, לכל אחד תפקיד
המתחרים משתמשים בשני צבעים עם תפקיד ברור: צבע כהה שבונה אמון, וצבע חזק לכפתורי הפעולה.
- Acronis — כחול כהה ולבן, עם הדגשות בצבע.
- Veeam ו-Cove — ירוק לצד אפור כהה.
- Datto ו-Druva — כחול כהה עם טורקיז.

אצלנו:

| תפקיד | ברירת מחדל | איפה |
|---|---|---|
| **צבע המותג** (אמון) | אינדיגו `#4F46E5`, על רקע כמעט-שחור `#070B16` | כותרת עליונה, לשונית פעילה, קישורים, מספרי שלבים |
| **צבע הפעולה** (מכירה) | כתום `#F97316` | הכפתורים שמקדמים את הלקוח: "גבה עכשיו", "יצירת החשבון שלי", "הורדה", "התקנה", ופס דק מתחת לכותרת |
| מצב | ירוק `#059669`, כתום-חום `#B45309`, אדום `#DC2626` | מוגן, אזהרה, תקלה |

- **כלל 60/30/10:** 60% רקע בהיר, 30% צבע המותג, 10% צבע הפעולה. כך הכפתור הנכון תמיד בולט.
- **ההיגיון המכירתי:**
  - כחול הוא הצבע המזוהה ביותר עם אבטחה ואמינות.
  - כתום הוא הצבע המשלים לכחול, ולכן הוא מושך את העין ומעלה את שיעור הלחיצות.
  - ירוק שמור ל"הכול תקין", כדי שהלקוח יראה מיד שהוא מוגן.
- **עיצוב עכשווי:**
  - כותרת בהדרגה מכחול-לילה לצבע המותג.
  - כרטיסים מעוגלים עם צל עדין.
  - לשוניות עם קו תחתון במקום לשוניות "תיקייה".
  - שדות עם מסגרת בצבע המותג כשעומדים עליהם.

## DESIGN-020 — צירופי צבעים מוכנים לשותף
בפורטל, בשלב "המוצר שלך", השותף בוחר צירוף. ליד כל צירוף מוסבר למה הוא מוכר:

| צירוף | מותג | פעולה | למי |
|---|---|---|---|
| **חדשנות + פעולה** (מומלץ) | `#4F46E5` | `#F97316` | ברירת המחדל — מתאים ל-AI |
| אמון + פעולה | `#1D4ED8` | `#F97316` | הנפוץ בתוכנות אבטחה |
| הגנה + צמיחה | `#0F3D3E` | `#10B981` | מי שמוכר שקט נפשי |
| פרימיום | `#1F2937` | `#EAB308` | עורכי דין, רואי חשבון, מרפאות |

- אפשר גם לבחור צבעים חופשיים.
- הצבעים נשמרים במיתוג כ-`COLOR` ו-`ACCENT`.
- הם מופיעים בכל מקום:
  - אתר הניהול;
  - תוכנת הלקוח;
  - שחזור מהאתר;
  - מיילים;
  - אשף ההתקנה.

## DESIGN-030 — מבט אחד: האם המחשב מוגן?
במסך הראשי של תוכנת הלקוח מופיע פס גדול:
- **ירוק** — "המחשב הזה מוגן".
- **כתום** — "מוגן חלקית".
- **אדום** — "נדרשת תשומת לב".

לכל גיבוי יש פס צבע בצד, לפי התוצאה האחרונה שלו.

## I18N-020 — השפה נקבעת לפי אזור הכניסה
סדר הבחירה:
1. **שפה שהמשתמש בחר בעצמו** — נשמרת בדפדפן וגוברת על הכול.
2. **האזור** — לפי אזור הזמן של המחשב שממנו נכנסים:
   - ישראל → עברית;
   - מדינות ערב → ערבית;
   - גרמניה, אוסטריה ושווייץ → גרמנית;
   - ספרד ואמריקה הלטינית → ספרדית;
   - ברזיל ופורטוגל → פורטוגזית;
   - צרפת → צרפתית;
   - איטליה → איטלקית;
   - הולנד → הולנדית;
   - פולין → פולנית;
   - טורקיה → טורקית;
   - יפן → יפנית;
   - סין, הונג קונג וטייוואן → סינית.
3. **אזור עם כמה שפות** (בלגיה, קנדה) — נבחרת השפה של הדפדפן מבין השפות של האזור.
4. **אזור שאינו ברשימה** (ארה"ב, בריטניה וכו') — שפת הדפדפן.
5. **אחרת** — שפת המוצר שהשותף הגדיר, ואם אין, אנגלית.

הכלל חל על כל המסכים: פורטל השותפים, אתר הניהול, תוכנת הלקוח, שחזור מהאתר ואשף ההתקנה.
אזור הזמן מגיע מהמחשב עצמו. אין שימוש בשירות חיצוני לזיהוי מיקום, ולכן אין שליחת מידע לצד שלישי.

## DESIGN-040 — מערכת עיצוב אחת: חדשנות ויוקרה
- קובץ עיצוב משותף לכל המסכים: `/i18n/theme.css`.
- **שלושה צבעים, לכל אחד תפקיד:**
  - **צבע המותג** — אמון.
  - **צבע הפעולה** — כפתורים.
  - **החתימה של ה-AI** — מעבר סגול → כחול → תכלת. מופיע **רק** איפה שה-AI עובד, כדי שהלקוח יזהה מיד "כאן ה-AI עובד בשבילי": תובנות, הסברי תקלות, שמירה מפני כופרה וחיפוש חכם.
- **כותרת עליונה:**
  - כמעט-שחורה, עם הילה של צבע המותג.
  - פס דק בצבעי ה-AI מתחתיה, כסימן היכר של המוצר.
- **גופנים מוטמעים** (רישיון SIL OFL, בלי בקשות לגוגל ועובדים גם בלי אינטרנט):
  - Inter — לטינית;
  - Heebo — עברית;
  - Noto Sans Arabic — ערבית.
- **עיצוב עכשווי:**
  - כרטיסים מעוגלים עם צל עמוק.
  - תפריט בצורת "גלולות", כשהלשונית הפעילה כהה.
  - שדות עם מסגרת זוהרת בפוקוס.
  - כפתור פעולה עם עומק.

## DESIGN-050 — ה-AI נראה, לא רק מתואר
- **פורטל השותפים ואתר האינטרנט:** "קונסולת AI" חיה עם דוגמאות למה ה-AI עושה:
  - שינוי חריג → גרסאות הוקפאו;
  - גיבוי נכשל → הסבר ותיקון, ונפתחה קריאת שירות;
  - דיסק יתמלא בעוד 41 יום.
- **אתר הניהול — תובנות:**
  - בראש העמוד לוח "ה-AI שומר על הגיבויים שלך" עם ארבעה מדדים.
  - בתפריט, ללשונית התובנות יש סימן ✦.
- **תוכנת הלקוח:** בפס הירוק מופיע "ה-AI שומר על כל גיבוי מפני כופרה", עם נקודה חיה.

## BRAND-010 — המותג בכל מסך
שם המוצר, הסלוגן והלוגו של השותף מופיעים בכל המסכים:

| מסך | איפה מופיע המותג |
|---|---|
| אתר הניהול | בכותרת, וגם בכרטיס הכניסה, עוד לפני הכניסה |
| שחזור מהאתר | בכותרת ובכרטיס הכניסה |
| תוכנת הלקוח | בכותרת ובחלון הכניסה. אם בחבילה אין מיתוג, התוכנה לוקחת אותו מהשרת שאליו היא מחוברת ושומרת עותק לעבודה בלי אינטרנט |
| אשף ההתקנה | בכותרת, מהשלב הראשון, כולל הצבעים |
| מיילים | בראש המייל |
| דוח הגנת המידע | בראש הדוח |

כששותף עוד לא הגדיר מיתוג, מוצג שם המוצר שלנו.
